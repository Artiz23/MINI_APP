# MINI_APP — один главный бот

Вход и уведомления в Telegram. Семь разделов в Mini App: Заявки, Согласование, Сальдо, Курсы, Праздники, Баланс, Комплаенс.

Старые боты курсов / согласования / сальдо не трогаются. Их логика курсов и праздников подключена отсюда.

## Секреты

Файл: `internal/secrets/secrets.go`

| Поле | Что писать |
|---|---|
| `BotToken` | токен главного бота из BotFather |
| `WebAppURL` | публичный `https://...` (кнопка «Открыть Mini App») |
| `ListenAddr` | по умолчанию `:8080` |
| `ForumChatID` | группа-форум для тем заявок, `0` если темы пока не нужны |
| `MainAdminIDs` | вы — сводка в 10:00, доступы, споры |

Чаты курсов и согласования сюда не нужны: всё в Mini App.

В BotFather у бота: Menu Button → Mini App → тот же `WebAppURL`.

## Сборка (запускаете сами)

Windows (из корня репозитория или из этой папки):

```powershell
powershell -File MINI_APP\build-windows.ps1
```

Linux / Debian:

```bash
bash MINI_APP/build-linux.sh
```

Бинарник: `MINI_APP/dist/windows/miniapp.exe` или `MINI_APP/dist/linux/miniapp`. Рядом должна лежать папка `web`.

## Запуск

1. Вписать `BotToken` и `WebAppURL`, пересобрать.
2. Повесить HTTPS на `ListenAddr` (nginx / caddy).
3. Добавить бота в группу-форум, если `ForumChatID` не ноль.
4. Операционистам доступ выдаёт владелец в Mini App → Доступы. Ответственный за баланс отмечается галочкой: только он получает напоминания 09:30 и 18:30.

Данные: `data/miniapp.json` рядом с бинарником. Связка: `uid` заявки / согласования / сальдо / счёта / проверки, ссылка на тему Telegram, `table_ref` после обработки.

## Сохранение заявки в документы

«Сохранить в документы» в списке или карточке заявки открывает выбор существующей папки или вкладки компании/контрагента. Сохраняется независимая копия на момент нажатия: карточка заявки, все прикреплённые файлы и их подписи, сообщения, оплаты, согласования, сальдо, задачи, обращения, комплаенс и связанные споры с перепиской.

В «Документах» комплект открывается одной карточкой. Можно просмотреть отчёт и вложения, скачать отдельный файл или весь ZIP. В ZIP находятся `report.txt`, полный снимок данных `request.json` и каталог `files`. Файлы одинакового имени сохраняются отдельно. Изображения, текст, PDF, аудио и видео имеют просмотр в приложении при поддержке браузером; остальные форматы скачиваются для открытия на устройстве.

После сохранения в заявке появляются «Открыть в документах» и «Удалить из документов». Удалять может сохранивший пользователь или администратор, в том числе из раздела «Документы». Удаление копии не меняет исходную заявку. Для обновления снимка удалите копию и сохраните заявку снова. Нужны доступы к заявкам и документам. Старые выгрузки отдельными файлами остаются обычными документами.

Архивы хранятся в `data/files` вместе с остальными вложениями; резервная копия должна включать всю папку `data`.

Проверки: `go test ./MINI_APP/...`. Браузерные тесты с тестовым API: `node --test MINI_APP/tests/archive-ui.test.cjs` (требуется Playwright; путь к установленному Chromium/Edge можно передать через `BROWSER_EXECUTABLE`).
